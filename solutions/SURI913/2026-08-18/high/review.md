시간복잡도 `O(N^2)`
> Checkpoint :  16진수 숫자(0~F)가 적혀 있는 보물상자, 보물상자의 비밀 번호=K번째로 큰 수를 10진 수로 만든 수, 크기 순서를 셀 때 같은 수를 중복으로 세지 않도록 주의
>
> 0회전 : 1B3, B3B, 81F, 75E <br>
> 1회전 : E1B, 3B3, B81, F75 <br>
> 2회전 : 5E1, B3B, 3B8, 1F7 <br>
> 3회전 : 0회전과 동일 <br>
> 
> len = N/4
> 
> 16진수 숫자(0~F)가 적혀 있는 보물상자 => string 입력 + 회전 처리<br>
> 크기 순서를 셀 때 같은 수를 중복으로 세지 않도록 주의 => set

이 방법 외의 구현방법
- 인덱스 값으로 회전한것 처럼 접근 `index = (start + offset) % N;`

string 입력 받고 <br>
회전대신 인덱스로 회전한것처럼 보냐 or 진짜로 회전하듯이 처리를 하냐의 차이<br>
시간복잡도는 동일하다 => 숫자변환이 결국 N^2 라서


set대신에
- vector + sort로 구현도 가능
