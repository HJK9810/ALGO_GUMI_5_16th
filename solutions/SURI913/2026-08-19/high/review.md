시간복잡도 `O(W^N)`
> Checkpoint :  구슬은 좌, 우로만 움직임. 벽돌은 숫자 1 ~ 9 로 표현되며,<br>
> 구술이 명중한 벽돌은 상하좌우로 ( 벽돌에 적힌 숫자 - 1 ) 칸 만큼 같이 제거.<br>
> 빈 공간이 있을 경우 벽돌은 밑으로 떨어지게 된다.N 개의 벽돌을 떨어트려 최대한 많은 벽돌을 제거.<br>
>
> 최대한 많은 벽돌 제거, 상하좌우 범위, N,W,D 의 범위를 봐서는 완전탐색 충분함.
> => DFS+백트래킹+BFS

상하좌우의 범위에서 -1씩 소거해야하니까 넓이탐색 -> BFS<br>
BFS + 좌표값과 hit범위값까지 확인해야하니 구조체 만드는 편이 좋음.

중력적용하는 부분은 단방향으로 탐색하는 것으로도 충분

```
for(w: 0부터 W-1까지)
  write = H-1;
  for(h: H-1부터 0까지)
    if(hitCount가 0이면) 넘어감;
    else {
      write위치에 값 저장;
      write--;
    }
```

후기: 단방향 탐색은 내용그대로 0이 보일때마다 내리는 것 보다 인덱스 값 하나 두고 한번에 내리는 편이 좋음.
